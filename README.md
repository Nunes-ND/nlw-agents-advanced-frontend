# NLW Agents Advanced Web

## About the project

This is the frontend for the **NLW Agents Advanced** application, an interactive platform for creating question and answer (Q&A) rooms. The application allows users to create rooms, share them with others, and interact through real-time questions and answers.

## Features

- **Room Creation:** Form to create new Q&A rooms.
- **Room Listing:** View available rooms.
- **Q&A Sessions:** Send and view questions within a room.
- **Audio Recording:** Functionality to record audio in the rooms.

## Technologies

This project was developed with the following technologies:

- **React**
- **Vite**
- **TypeScript**
- **Tailwind CSS**
- **Radix UI**
- **Lucide React**
- **React Hook Form**
- **Zod**
- **React Router DOM**
- **TanStack React Query**
- **Biome** (for linting and formatting)

## How to run the project

```bash
# Clone the repository
$ git clone https://github.com/Nunes-ND/nlw-agents-advanced-web.git

# Access the project folder
$ cd nlw-agents-advanced-web

# Install the dependencies
$ npm install

# Run the application
$ npm run dev
```
